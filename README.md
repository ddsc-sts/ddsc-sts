## Como eu trabalho

- **Primeiro entendo o problema, depois escrevo código.** Gosto de modelar os dados antes de abrir o editor.
- **Código limpo vem antes de código esperto.** Se outra pessoa não consegue ler, ainda não terminei.
- **Testo o que construo.** Funcionar na minha máquina não basta.
- **Trabalho bem em equipe.** Dois dos meus projetos principais foram feitos em grupo.
